Build a full-stack Progressive Web App (PWA) for a personal habit and productivity tracker using React, Tailwind CSS, and Lucide icons.

The application must include:
1. Dashboard View:
   - Daily habit completion checkboxes with a visual progress bar.
   - Current streak counter for each habit.
   - A toggle between daily, weekly, and monthly views.

2. Analytics Tab:
   - A chart showing completion consistency over the last 30 days.
   - Summary statistics (total completed, current best streak).

3. Local Persistence & Customization:
   - Save all user data in localStorage so state persists on refresh.
   - Allow users to add, edit, or delete custom habits with color tags.
   - Dark mode toggle in the header.

4. UI/UX Requirements:
   - Responsive design optimized for both mobile screens and desktop sidebars.
   - Smooth micro-interactions and animations when completing a habit.
   - Use a modern slate/indigo color palette with high-contrast text.

Provide the complete executable code across separate files (index.html, App.jsx, styles.css) with no placeholders or missing functions.
